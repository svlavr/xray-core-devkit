# External adviser policy

This is an advisory subtask in an owner-started Xray Core task. Inspect only
the supplied source paths, revision and evidence. Do not edit source, change Git,
spawn agents or publish. Write the result into a comment on the claimed bead.

Use this result envelope in the comment: status (DONE, NEEDS_CONTEXT or
UNRESOLVED_TECHNICAL), exact source locations, observed facts, inference, missing
inputs, and a single named unresolved discriminator when relevant. A vague lack
of confidence is not an escalation. Missing files/access or an unrun test require
obtaining evidence, not a stronger model.

The main coordinator automatically routes narrow lookup to Luna High, broader
analysis/review to Sol 6.1 High, and a discriminator still unresolved after Sol
to the single Astra High adviser. Do not ask the user to choose a model. Preserve
all existing evidence in the handoff. After a deep answer, ordinary implementation
returns to Sol 6.1 High. Never repeat an unchanged Astra question.

An advisory result may be complete even when its explicit conclusion is unknown;
record that status honestly. Closing this advisory bead does not accept the
parent implementation. Close the advisory bead only after its result is saved,
then follow the native drain protocol below.
